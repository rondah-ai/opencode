Execute test workflows — step-based flows or capability-based plans.

Two modes:

STEP MODE (default):
- Runs predefined flow steps from QA_FLOWS.json (navigate, click, type, verify)
- Each step executed sequentially with parameter substitution
- Screenshots captured at key moments
- Detailed execution log with pass/fail per step

CAPABILITY MODE:
- Executes a capability plan generated by compose_test (smart mode)
- Each capability describes what to do in natural language
- Agent uses scan_page, browser_interact, verify_behavior to fulfill each step
- Verify checks run per capability to confirm expected outcomes
- Supports shared capabilities (login, etc.) and feature dependencies

Step mode parameters:
- flowPath: Dot-notation path to flow (e.g., "callLogs.viewCallDetails")
- params: Key-value pairs for parameter substitution
- takeScreenshots: Auto-capture screenshots (default: true)
- stopOnError: Stop on first error (default: true)
- baseUrl: Override base URL (optional)

Capability mode parameters:
- mode: "capability"
- plan: Array of capability steps from compose_test metadata.plan
- takeScreenshots: Auto-capture screenshots (default: true)
- stopOnError: Stop on first error (default: true)

Step mode examples:
  execute_flow("callLogs.viewCallDetails")
  execute_flow("authentication.login", {email: "test@example.com", password: "pass123"})

Capability mode example:
  1. result = compose_test("regression test call_logs")
  2. execute_flow(mode="capability", plan=result.metadata.plan)

Output: step-by-step execution log, pass/fail per step, timing, screenshots.
